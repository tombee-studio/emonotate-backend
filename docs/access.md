# 役割と操作の対応表

API と旧入力画面で許可する操作。自動テストは `backend/apps/users/test/test_access.py`。

| 対象 | 参照 | 作成 | 変更 | 削除 |
|---|---|---|---|---|
| 利用者 | 本人 | Cognito のみ | Cognito のみ | Cognito のみ |
| 依頼 | 依頼者・参加者・招待関係のある研究者 | General・Researchers | 依頼者 | 依頼者 |
| 依頼の参加者（メールアドレスを含む） | 依頼者 | 依頼者 | 依頼者 | 依頼者 |
| 依頼への回答 | 本人・依頼者（一覧と出力は依頼者） | 依頼者・参加者 | 本人（ロック前） | 本人（ロック前） |
| 曲線（依頼以外） | 本人 | ログイン済みの全員 | 本人（ロック前） | 本人（ロック前） |
| アップロードした素材 | 所有者・所有者の依頼の参加者 | 本人 | 所有者 | 所有者（使用中は不可） |
| YouTube などの素材 | ログイン済みの全員 | 下記 | 所有者 | 所有者（使用中は不可） |
| 評価軸 | ログイン済みの全員 | General・Researchers | 所有者 | 所有者（ほかの利用者が使用中は不可） |
| 区間情報・Google フォーム | 所有者・それを使う依頼の依頼者と参加者 | Researchers | 所有者 | 所有者 |
| 設問 | ログイン済みの全員 | Researchers | Researchers（回答済み・ほかの依頼で使用中は不可） | 同左 |

- 素材の作成は、YouTube はログイン済みの全員、その他は General・Researchers。
- 依頼を作るとき、曲線を保存するときは、参照できる素材だけを指定できる。
- ほかの利用者について API が返すのは ID とユーザ名だけ。メールアドレスは、依頼者が見る参加者一覧・回答の一覧・出力、招待関係の一覧に限る。
- ユーザ名に `@` を含む利用者は、ほかの利用者には「利用者ID」と表示する（ユーザ名からメールアドレスが分からないように）。
- 依頼メールの送信は POST だけを受け付ける。
- 依頼に設定できる区間情報と Google フォームは、依頼者自身が作ったものだけ。参加者は依頼の応答で内容を受け取る。
- 依頼への回答は、受付期間外と提出回数の上限を超えた場合に拒否する（依頼者も同じ。保存済みの回答の変更は受付期間内だけ）。
